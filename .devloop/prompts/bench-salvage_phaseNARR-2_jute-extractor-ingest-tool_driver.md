## 5. Acceptance criteria

Each criterion is a **test written first** (the deterministic gate the cycle and the critic hang on).

- **A1 — the structural output-invariant rejects a bad extraction.** A mis-joined template (wrong join
  key) whose apply yields a `null`/short array scores **0** and is rejected; a clean template scores
  pass. Test `tests/verification/test_jute_extractor.py::test_extraction_metric_enforces_zero_null_and_count`.
- **A2 — the proven §4.2 template yields 5 admissible narrative cases.** Feeding the §4.2 template +
  the fixture session through `score_extraction` (mock `EtlpJuteClient.apply_mapping` returning the
  per-scene apply result) yields **5** records, each matching the §4.1 envelope AND admissible under
  `pack=narrative` (`expected_safety_flags ⊆ the narrative tier union`).
  Test `test_jute_extractor.py::test_proven_template_yields_five_admissible_cases`.
- **A3 — `ingest_cases` presents then pins + audits on accept, deny-default holds.** Drop JSON → the tool
  generates (mock generator) → presents N cases → on accept calls `persist_or_update` exactly once,
  writes one `AuditRecord`, upserts the corpus (per D-C), and emits a `corpus` focus part; an invariant
  failure / `:3031`-down path surfaces a structured error and pins **nothing**.
  Test `tests/bff/test_ingest_cases_tool.py::test_ingest_presents_then_pins_on_accept` (+ a `…_pins_nothing_on_invariant_fail`).
- **A4 — trust-model separation: the extractor is NOT a floor contract.** The `jute_transform` extractor
  tool-type is absent from `_FLOOR_CONTRACT_TYPES` / the grade-time contract registry; the moat + the
  floor-contract set are unchanged by this cycle.
  Test `test_jute_extractor.py::test_extractor_is_not_a_grade_time_floor_contract`.
- **A5 — the tool registry grew by exactly one (the 17th), the A-SAFE deny hook is byte-unchanged.**
  `_TOOL_SPECS` length increased by 1 and contains `ingest_cases`; `_deny_non_lithrim` is byte-identical.
