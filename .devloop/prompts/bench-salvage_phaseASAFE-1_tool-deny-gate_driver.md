allowlist non-binding; the live agent has + uses built-in tools (`Bash`). The product's core trust

system prompt persona, which the agent followed when asked directly but bypassed when it improvised a
config lookup. This cycle makes the floor **real**: a deterministic tool-layer deny gate + SDK
isolation, proven **live** (closing the stub-vs-real verification gap that hid this for four cycles).

(per `self-asserting-loop-honesty-moat`): *we ran it live, caught the hole our offline proofs missed,
and enforced the floor.* That find→fix is a stronger proof of the thesis than a clean pass.
