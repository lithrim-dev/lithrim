ontology (`app.py:681`, `agent_template_endpoint` reads `ws.pack` `:719`).

- `TIER_1_NEVER_EVENTS`: `BRACKET_LEAK`, `SILENT_DEGRADATION` (a degraded/filtered generation shipped as complete — a trust failure).

- `tier1_owners`: `BRACKET_LEAK → policy_judge`, `SILENT_DEGRADATION → risk_judge`.
- `production_judges`: `["risk_judge","policy_judge","faithfulness_judge"]` (CORE names only).
- `lenses` (every gradeable code ∈ ≥1 role; owner↔emit — no orphan codes, no inert owners): e.g.
  `policy_judge`: BRACKET_LEAK, LENGTH_VIOLATION, POV_VIOLATION, LANGUAGE_DRIFT, CLICHE_OVERUSE, REPETITION;
  `risk_judge`: SILENT_DEGRADATION, MODE_INAPPROPRIATE;

- `declared_but_not_running:[]`; `snapshot_metadata` noting source = NARR-1 + that it is hand-authored
  (read-only at grade time per the CLAUDE.md core invariant; NOT a `snapshot_taxonomy.py` harvest).

**D3 — `packs/narrative/ontology.json`** — mirror `support_ticket_qa/ontology.json`. Each code from D2
as a flag with `gradeable:true`, its tier, `owner_roles` (⊆ the role(s) that carry it in `lenses` —
**owner↔emit**), severity, and a narrative `question`. Every `gradeable` flag's code MUST be ∈ the D2
snapshot tier union (else `gradeable_flags_outside_snapshot` 422s). Floor-layer codes (BRACKET_LEAK,
LENGTH_VIOLATION, POV_VIOLATION, LANGUAGE_DRIFT, SILENT_DEGRADATION, CLICHE_OVERUSE, REPETITION) ship
here as gradeable **judge** flags ONLY; their deterministic `verification_contract` executors are
**NARR-3**, not this cycle.

**D4 — `packs/narrative/council_roles/{risk_judge,policy_judge,faithfulness_judge}.txt`** — narrative-
domain role prompts (mirror the support_ticket_qa prompts' shape; rewrite the domain content for
grading AI-generated story scenes). Suggested split: `policy_judge` = the enhancement prompt's own
authored contract (no brackets, length, POV, language); `risk_judge` = trust/degradation
(SILENT_DEGRADATION, mode-appropriateness); `faithfulness_judge` = coherence with the authored body +
fidelity to theme/tone/lesson + honoring the reader's bridge answers. Each role's prompt must be able
to raise exactly its `lenses` codes.

**D5 — `packs/narrative/examples/narrative_v1.jsonl`** — one (or a few) per-scene StoryWorld eval-case
in the §4.1 envelope, **clean-negative** (`expected_safety_flags:[]`, `injection_recipe:null`,

from the pasted Jinn session. Unlabeled by construction (HONEST-1) — this is the admissibility +
standalone-grade fixture, NOT a labeled gold set (labels are an SME step, post-NARR-3).

**D6 — `tests/test_narrative_pack.py`** (offline, `$0`; RED-first). Mirror `test_standalone_ce.py` +
