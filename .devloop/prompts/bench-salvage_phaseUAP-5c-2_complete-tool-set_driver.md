## 0. Why this phase (complete the "complete tool set")

UAP-5c grew the conversational spine to the full journey on a 6-tool surface and ended in the cleanest A-SAFE state the product has had — *no* agent-reachable paid-capable op (the fresh-critic's grep for any paid path was empty). UAP-5c-2 is the pre-authorized split that finishes the tool set: the **eval-pack batch** (`run_eval_pack` — run a pack of agents, review the batch) and the **Domain-assembly write** (`assemble_agent`). It deliberately re-introduces (a) the first **paid-capable** wrapper and (b) the first agent-reachable **Agent WRITE**, so A-SAFE is the gate-decider again — and the cycle's value is partly *proving the floor holds as the surface widens*.

**The right-size finding (monitor pre-scan, `live-reassess-before-driver-lock`):** `run_eval_pack` is clean and genuinely new (the batch carries `pipeline_run_id`, so it round-trips to the existing Review surface). `assemble_agent` is the trap — a full Agent dict is too much for a conversational tool to build — so it must be **edit-one-facet** (load→modify→put, the agent supplies a delta), the same discipline that made `author_flag` safe. If edit-one-facet still balloons, ship `run_eval_pack` alone (D-F).
