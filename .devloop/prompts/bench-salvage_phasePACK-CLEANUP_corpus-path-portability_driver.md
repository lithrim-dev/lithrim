1. **`lithrim_bench/synthea_loader.py`** (~:69) and **`lithrim_bench/synthea_fhir_loader.py`** (~:71) — when the cohort dir is **under `REPO_ROOT`**, store `cohort_path` as the repo-relative POSIX string (mirror `build_fhir_mini_pack.py:84`: `.resolve().relative_to(REPO_ROOT)`). **Fallback:** if the cohort dir is NOT under repo root (e.g. an out-of-tree absolute path), keep the absolute string — do **not** crash. If any other field moves, **halt and surface** — do not ship a drifted corpus.

The leak is the identical exact full-value string in every row, so in-place makes the guardrail provably airtight; regen risks a benign non-`cohort_path` drift (e.g. a timestamp) tripping the halt for no reason. A2 already regenerates `judge_calib` into `tmp_path` with the **D1-fixed loader** and compares to committed — that is the end-to-end proof D1 works, so no committed corpus needs regenerating.
