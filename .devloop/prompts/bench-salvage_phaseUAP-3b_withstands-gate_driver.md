## 0. Why this phase (the moat made operational — and the S-BS-70 payoff)

UAP-1/2/3 built author→process; UAP-5a mounted the authoring UI + a legible authored
audit. But UAP-5a's **A4 live verdict-flip FAILED (S-BS-70):** assigning a *base-owned*
flag can't flip a real verdict, because the base trio already catches the by-construction
defect — authoring only sharpens an already-firing lens. The fresh-critic + monitor both
concluded: **a genuine "watch the verdict change" needs a defect the LLM judges get WRONG
that a DETERMINISTIC signal corrects.** That is exactly the §2A **withstands-gate** — and
it is THE MOAT.

The building blocks all exist — LLM judges (`runtime/council`), validators
(`verification/`), grounding (`harness/grounding.py`), the ontology rules
(`harness/ontology.py`). **The NET-NEW is the ORCHESTRATION** (SPEC line 74): assemble,
per judge, its **signals** — the assigned **ontology rules** (tier / owner / when /
when-NOT / severity) + the executed **validator/grounding outputs** — and run a
**Ralph-Loop-like critique** that admits a judge's verdict **only if its reasoning
withstands those signals**; a signal-contradicted finding is **corrected**. This
*generalizes* the S-BS-7 post-consensus suppress + the WS-3a structural floor into a
**per-judge, pre-consensus** gate.

The `critique-pass-precision-not-floor` spike is the load-bearing prior: a transcript-only
*self*-critique CANNOT flip a transcript-only blind spot — **feeding the critique the
ontology + validator signals is what makes it GROUND rather than merely self-critique.**
So the deterministic signals are the floor; lead with them.

**Invariants (SPEC lines 71-74, non-negotiable):** the whole gate lives **ABOVE the
frozen `compliance_council._apply_consensus`** (byte-0-delta). Validators/grounding stay
**deterministic** (no LLM in the floor). The critique can **down-rank or correct** a
judge's reasoning but **CANNOT relabel a by-construction case** (labels-true-by-construction
— `CLAUDE.md`).

**Locus = BOTH (SPEC line 268):** the per-judge Ralph-Loop critique is the NEW **primary**
gate over the LLM judges (a **pre-consensus** stage, inserted in `authored_stage`); the
existing post-consensus `harness/grounding` serves the **independent** GroundingChecks.
